# MicrosStreaming

Sitio estatico de guias sobre micros para streaming.

URL: https://poemasbiblicos.github.io/microstreaming.github.io/

## Como editar

1. Edita el contenido en `content.py`.
2. Ejecuta `python build.py`.
3. Haz commit y push: GitHub Pages publica la rama `main` desde la raiz.

El HTML generado (`index.html` de cada carpeta), `sitemap.xml` y `robots.txt` se
crean automaticamente. No los edites a mano.
